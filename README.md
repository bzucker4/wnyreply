# WNYReply

Lead-response landing page for Western New York trades and service businesses.

## What works

- Click-to-text demo using `(585) 502-9426`
- Founding-member application captured by Netlify Forms
- Spam protection through a honeypot field
- Dedicated confirmation, privacy, terms, and 404 pages
- Responsive layout and keyboard-visible focus states
- Netlify security headers

## Deploy

Import this repository into Netlify and keep the default build settings. The publish directory is the repository root. After the first deployment, submit one test application and confirm it appears under **Forms → founding-member-application**. Add an email notification in Netlify so new applications reach the business inbox.

## Before a public launch

Confirm that the SMS demo at `(585) 502-9426` is active and replies correctly. The website does not contain or expose messaging-provider credentials.
